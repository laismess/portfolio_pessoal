Projetos

Alguns projetos e atividades que representam minha evolução na área de desenvolvimento.

Primeiro Projeto – Cálculo de Média

Este projeto em Python foi criado para praticar o ciclo Entrada → Processamento → Saída.
O programa solicita o nome do aluno e duas notas, calcula a média e mostra se o aluno foi aprovado ou reprovado.

Ver projeto
Segundo Projeto – Consumo de Energia

Este projeto em Python foi criado para calcular o consumo mensal estimado em kWh.
O programa solicita o nome do aparelho, potencia e tempo medio e, calcula o cosumo mensal do usuário estimado por um valor fixo de 0,75 por kWh.

Ver projeto
Terceiro Projeto – Consumo de Água

Este projeto em Python foi criado para calcular o consumo mensal de água em m3 (metros cúbicos).
O programa solicita o tipo do ímovel, e o cosumo mensal de agua e, calcula o consumo mensal de agua do usuário analisa se está bom ou precisa melhorar.
